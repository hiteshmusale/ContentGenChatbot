# Skill: Generate from scratch
swimlane: generate
workflow: generate_email
label: Generate from scratch

## When to use
The user wants a brand-new promotional email written from scratch.

## Inputs
- product (required): Product the email is about
- persona (required): Target audience persona
- objective (required): What the email should achieve (e.g. launch announcement, reminder)
- key_message (required): The main message or angle to convey
- cta (optional): Call-to-action wording or destination

## Plan wording
State the product, persona and objective, then list the approved claims that will be
used verbatim, and the knowledge-base document versions applied.

## Failure modes
- User gives a product or persona that is not in the knowledge base: list the options.
- Request for claims that do not exist: explain only approved claims can be used.
